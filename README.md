# Go Java Pebble

Inpired by [`go-blade`](https://github.com/gusbemacbe/go-blade), forked from an archived and dead [fatrbaby/go-blade](https://github.com/fatrbaby/go-blade), resurrected, modernised and upgraded by me.

A Java templating engine written in Go, inspired by [Pebble Templates](https://pebbletemplates.io/). Ideal for static web projects written in Go and used and integrated by [Panforge](httos://github.com/gusbemacbe/panforge), that invokes Pandoc, and is based on the `pdsite` project, written in Bash and created by me.
